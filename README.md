# Day 22: Cohort Retention Analysis

## Project Overview

This project focuses on understanding customer retention using cohort analysis. Customers are grouped according to their signup month, and their purchasing activity is analyzed across subsequent months.

The project uses Python, Pandas, Matplotlib, Seaborn, and SQL to analyze customer behavior and revenue patterns.

## Objectives

* Understand the concept of cohort analysis.
* Group customers by signup month.
* Calculate monthly active customers and customer retention rates.
* Visualize retention patterns using a cohort heatmap.
* Analyze cohort-wise revenue using SQL.
* Generate business insights from customer purchasing behavior.

## Dataset Description

The dataset contains synthetic customer order information with the following columns:

* `customer_id`: Unique customer identifier
* `signup_date`: Date the customer registered
* `order_date`: Date of the order
* `order_id`: Unique order identifier
* `order_amount`: Revenue generated by the order

## Project Workflow

1. Load and inspect the dataset.
2. Clean and prepare the data.
3. Assign customers to signup-month cohorts.
4. Calculate the cohort index for each order.
5. Create a cohort retention table.
6. Visualize customer retention using a heatmap.
7. Create an SQLite database and perform SQL analysis.
8. Analyze cohort size, monthly active customers, and total revenue.
9. Summarize the business insights.

## SQL Analysis

The project includes SQL queries to calculate:

* Customer count by signup cohort
* Monthly active customers by cohort
* Total revenue generated by each cohort
